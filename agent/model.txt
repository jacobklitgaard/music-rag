Provider:  Ollama (local)
Model:     nomic-embed-text (768 dimensions)

Why OpenAI and not a local Ollama chat model:
The Agents builder talks to models through the OpenAI Responses API. Ollama's OpenAI-compatible
endpoint only partly supports it: plain chat worked, but tool calls and conversation history failed
with "unknown input item type: item_reference". An earlier version used n8n's AI Agent node with
Ollama qwen2.5:7b, which worked but under-used the vector tool and does not meet the brief's
requirement to use the Agents builder.
